# Mid-term 2 – Dự án 2: Phân tích dữ liệu Bank Marketing (Nhóm 16)

Dữ liệu: [Bank Marketing Dataset – Kaggle (janiobachmann)](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset), file `bank.csv` (11.162 dòng × 17 cột).

## Nội dung repo
| File | Mô tả |
|---|---|
| `NHOM16_PRJ2_MID_TERM_FINAL.ipynb` | Notebook chính thức, 4 giai đoạn, đã chạy sẵn kết quả |
| `bank.csv` | Dữ liệu gốc |
| `figures/`, `tables/` | Hình (PNG) và bảng số liệu (CSV) do notebook tạo ra |
| `NHOM16_PRJ2_BaoCao.pdf` | Báo cáo PDF |

## Cách chạy
1. Mở notebook bằng Google Colab.
2. Upload `bank.csv` vào Colab (hoặc để notebook tự đọc từ GitHub Raw).
3. Chọn **Runtime → Run all**. Ô 1.2c sẽ kiểm tra dữ liệu đúng bản gốc trước khi phân tích.
